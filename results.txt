Evaluation file: data/evaluation_set.csv

Evaluation style: manually curated synthetic Twitter-style support messages

Escalation: rule-based engine with anger, confidence, feature-request, billing-risk, and unknown-intent rules

The evaluation set contains 100 rows: 54 escalation-positive cases and 46 escalation-negative cases.

==== BASELINE COMPARISON ====

Model                                  Intent Accuracy    Escalation F1
Dummy majority baseline                 40.0%              0.70
Keyword matching baseline               66.0%              0.74
Embedding KNN model                     78.0%              0.85

Dummy baseline definition:
Always predicts billing_issue for intent. For escalation, it predicts YES for billing_issue, complaint_angry, and feature_request style messages using simple label priors.

Keyword baseline definition:
Uses direct keyword matching for words such as refund, charge, login, password, crash, bug, angry words, feature, add, thanks, and love. It fails on paraphrases and mixed-intent messages.

Embedding KNN model definition:
Encodes each message with all-MiniLM-L6-v2, compares it against labelled training examples with cosine similarity, and assigns the intent from the nearest neighbours.

Interpretation:
The escalation system is stronger than intent classification because escalation uses explicit rules in addition to model confidence. False negatives are the main risk because a missed escalation can leave a frustrated or blocked customer with an automated response.

==== CONFIDENCE DISTRIBUTION ====

Confidence score source:
The confidence value is the mean cosine similarity of the winning nearest-neighbour intent group. It is not a calibrated probability.

Plot description:
The confidence distribution is right-skewed, with most correct predictions between 0.65 and 0.90. Incorrect predictions cluster near the decision boundary from 0.45 to 0.65. A vertical threshold line at 0.60 separates uncertain predictions from normal automated handling. The plot supports using low confidence as an escalation signal, but it also shows that confidence should not be treated as a true probability.

==== KEY TAKEAWAYS ====

1. The model reaches 78.0% intent accuracy on the 100-row evaluation set.
2. Escalation F1 is 0.854 because rule-based escalation catches most high-risk cases.
3. Billing imbalance helps overall accuracy and should be disclosed.
4. Complaint classes remain the most error-prone because tone and intent overlap.
5. Confidence is useful for ranking uncertainty, but it is not calibrated.
